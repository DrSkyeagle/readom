# 还没做完的事

这份清单回答一个问题：**现在还差什么。** 分三类——已知故障、还没走过的验证、设计好但没做的；每一项在 GitHub Issues 里都有一条（编号写在项目后面），进展和讨论在那里。最后附一份上机验过的总清单（对照用）。已经结了的条目移到本页最后的「已结的条目」，留作记录；已经决定不改的取舍在 `known-issues.md`。

只在一台 PW3（固件 5.16.2.1.1）上开发和实测，所以"上机验过"指的都是这一台。
