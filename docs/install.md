# 安装说明

> 2026-11-01 修订。英文版：`install.en.md`。**v0.1.0 在一台 PW3 上走完过一次干净安装（真的从网上下载）；再往前，2026-10-19 走过一次用离线包的完整安装和一次只换系统的升级**，下文的时长就是这几次的实测值（按 Kindle 盘上日志文件夹的时间算）。还没验过的事情列在 `open-items.md`。书库里的条目叫"Readom"。

## 适用的设备

| 条件 | 怎么查 |
|---|---|
| Kindle Paperwhite 3（第 7 代，2015 年） | 设置 → 设备选项 → 设备信息 |
| 系统版本 5.16.2.1.1 | 同上。版本更早的见下文「系统版本更早怎么办」 |
| 已越狱，书库里能运行 `.sh` 小程序 | 按 [kindlemodding.org](https://kindlemodding.org/jailbreaking/) 的教程越狱。越狱与本项目无关，请自行判断风险 |

型号或版本不对时，安装器会显示 E101 并停止，不改动任何文件。

### 系统版本更早怎么办

5.16.2.1.1 是亚马逊给 PW3 出的**最后一个固件**（2023 年 8 月），之后没有新版本。所以只要这台机器联过网，它就是这个版本；停在更早版本的，一般是当年越狱后关掉了自动更新。更新回来就能装，步骤和拷安装包一样，不需要 Wi‑Fi：

1. 在电脑上打开亚马逊的 [Kindle 固件下载页](https://www.amazon.com/gp/help/customer/display.html?nodeId=GKMQC26VQQMM8XSW)，找 **Kindle Paperwhite（第 7 代）**，下载 `update_kindle_all_new_paperwhite_5.16.2.1.1.bin`（约 258 MB）。**别下成别的机型的**，型号不对装不上。
2. 接数据线，把这个 `.bin` 拷到 Kindle 盘的**根目录**（不是 `documents`，和安装包不是一个地方），弹出，拔线。
3. 设置 → 设备选项 → 升级 Kindle。升完自己重启，看一眼设备信息里的版本号。
4. **升级会清掉越狱**（除非当年装过 Kindle Jailbreak Hotfix）。升完看书库里还有没有"Readom"：没有就按上面的教程重新越狱一次，`Readom.sh` 本身不会被升级删掉。
5. 再点书库里的"Readom"。

## 需要准备

- 一根数据线和一台电脑（Windows、macOS、Linux 都可以，只用来拷文件）。
- Kindle 上至少 **2.6 GB** 空闲空间。（安装器自己算的是 2.49 GB：系统镜像 512 MiB、数据空间 1.75 GiB，加 64 MiB 余量。不够时屏幕上写着还差多少 MB。）
- 电量 40% 以上，或者接着充电器。
- 能访问 `github.com` 或 `readom.app` 的 Wi‑Fi——安装器带着这两个地址，按这个顺序试，哪条通用哪条。两条都取不到也没关系：在电脑上多下载一个离线包（见下）。

## 安装

1. 在本项目的发行页下载 `Readom.sh`（约 8 MB）。
   - 如果 Kindle 连的网络取不到安装包，再下载同一页面的 `readom-system-<版本>.img.zst`（约 191 MB），这就是离线包。
2. 用数据线把 Kindle 接到电脑，打开电脑上出现的 Kindle 盘。把 `Readom.sh` 拷进 `documents` 文件夹。如果下载了离线包，也拷进去。
   - **电脑上没出现 Kindle 盘**：先按一下电源键把 Kindle 唤醒再看。休眠时它可能只充电、不把存储交给电脑（2026-10-22 在本机遇到过：USB 上认得到这台设备，但电脑上没有盘）。还是没有就换一根数据线（有些线只有电源线，没有数据线）或换一个 USB 口。
3. 在电脑上"弹出"Kindle，再拔线。拔线后可以接充电器；安装过程中不要再接电脑。
4. 在 Kindle 的书库里点"Readom"。
   - 屏幕会依次显示：检查 → 下载（用了离线包就跳过）→ 核对 → 安装第 1 步 → 安装第 2 步，每步都有进度条。
   - 首次安装**实测约 15 分钟**（2026-11-01，v0.1.0，从点"Readom"到装完，含下载 188 MB 和解压）。用离线包的那次（2026-10-19，更早的构建）约 18 分钟，不含下载。两次是不同的构建、不同的网络，差值不是提速，只是说这件事大约一刻钟。最慢的是第 2 步：要在 Kindle 上写出约 1.9 GB 的数据空间。
   - 装完自动启动 Android，约 3 分钟，这期间屏幕不变。
5. 装好后，离线包会自动删除。`Readom.sh` 留着，以后从书库点它进入 Android。

中途没电、强制重启，或者不小心退出了，都没关系：再点一次"Readom"，会从断点接着装。下载也会从断点接着下——只有服务器不接受续传时才会重新下载，那种情况屏幕会让你再点一次。

## 平时使用

- **进入 Android**：在 Kindle 书库里点"Readom"，约 3 分钟。
- **回到 Kindle 原来的系统**：在 Android 里长按电源键，选"重启回 Kindle 系统"。
- **卡住时**：先等两分钟。启动检查没通过时，设备会自己重启回 Kindle 原来的系统。两分钟后还没动静，就**按住电源键不放，直到屏幕变化**——最多约 40 秒，同样回到 Kindle 原来的系统，数据不会丢。（不要只按十几秒就松手：硬件复位的确切时长在这台机器上没有计过，亚马逊自己的说明是 40 秒。）
- **屏幕一直显示"正在启动 Android"**：这是正常的，整个过程屏幕不变。只有屏幕反复闪烁才是没能启动。
- **装一个应用要多久**：用"文件"应用打开 APK 再点安装。大应用要一两分钟，屏幕上会写"正在为本机准备应用…"。这台机器没有 GPU，应用的代码要先在本机转换一遍，所以比手机慢；装完之后启动就和平时一样了。
- **装好的应用在哪**：自己装的应用会出现在首页的空格里。首页还有一格"全部应用"，点开是这台机器上所有应用的列表（在首页上滑也能打开同一个列表）。

## 升级

把新版的 `Readom.sh` 拷进 `documents`，覆盖旧的，再点"Readom"。已装的应用和数据都保留。

只换系统、不动数据的升级**实测约 5 分钟**。

少数升级（换了启动镜像的那种）要为新系统重新编译已装的应用，这时启动前的画面会写明。**一个大应用大约三到五分钟**（启动画面上写的就是这个数，故意比实测宽）：微信读书这种 127 MB 的实测，用过一段时间、系统已经攒下使用画像的 159 秒；还没攒下的 60–93 秒。请接上充电器，不要强制重启。中途重启不会损坏数据，只是正在编译的那个应用要从头再来。

如果这次启动被打断了（没电、手滑重启），下一次还是要从头编译。所以"要编译、请耐心"这个提示会**一直显示到真的编译完为止**，不管你点了多少次：Android 每次启动都会在 Kindle 盘上留下一份报告，原厂这一侧读它，看到"这个系统完整启动过一次"才把提示收起来。

## 卸载

用电脑打开 Kindle 盘，删除 `android` 文件夹和 `documents/Readom.sh`。Kindle 原来的系统和书都不受影响。

只想清空 Android 的数据（相当于恢复出厂设置）：只删除 `android/data.img`，再点"Readom"，会生成一个空的。

**下载到一半不想装了**：删掉 `android/download` 这个文件夹就行，最多 191 MB 的空间立刻回来，已经装好的 Android 不受影响。装成功时安装器自己会清掉它，所以平时里面是空的。

## 出错时

屏幕上会显示错误码和中英文说明。

| 错误码 | 意思 | 怎么办 |
|---|---|---|
| E101 | 型号或系统版本不支持 | 没有改动任何文件。机型对得上、只是版本更早的，见上文「系统版本更早怎么办」 |
| E102 | 电量低于 40%，又没在充电 | 充电后再点 |
| E103 | 上一次的安装还在进行 | 等它完成 |
| E104 | Kindle 还连着电脑 | 在电脑上「弹出」Kindle 盘，拔掉数据线，再点一次。接充电器没有关系 |
| E201 | 下载中断 | 检查 Wi‑Fi 后再点；能接着下的会接着下，接不上就重新下。也可以改用离线包 |
| E202 | 需要下载，但 Wi‑Fi 没连 | 连好 Wi‑Fi 再点；或者把离线包拷进 `documents` |
| E203 | 无法确认下载是否安全 | 最常见的原因是 Kindle 的日期时间不对，先在设置里核对；证书校验没通过也是这个码 |
| E302 | 安装包不完整或损坏，已删除 | 再点一次会重新下载，或者重新拷贝 |
| E303 | 这个版本的发行文件有问题 | 不是你的问题，请到项目主页报告 |
| E304 | 已有的 Android 数据来自不兼容的版本 | 继续用原来版本的 `Readom.sh`。**如果你从来没装过 Android**，那就是 `android/data.img` 是别的来源留下的——用电脑删掉它再点一次 |
| E401 | 空间不够 | 屏幕上显示还差多少 MB，删一些书再点 |
| E402 | 读写存储出错 | 重启 Kindle 后再点 |
| E403 | 内存不够 | 重启 Kindle 后再点 |
| E404 | 盘上的文件系统有问题：要写的位置和另一个文件共用 | **没有往那里写（书还是原样）。**用数据线连到电脑，让电脑检查并修复这个 Kindle 盘，然后再点 |
| 没能启动 | Android 没有启动成功，已回到 Kindle 原来的系统 | **再点一次**：没能启动的原因留在了盘上，下一次点击会读到它，该重装的会自己重装（见下） |
| 屏幕上只有一行英文 `ANDROID DID NOT START. FREE SOME SPACE…` | Kindle 盘连一个空目录都建不出来了（彻底满） | 接电脑删掉一些书再点。这一行是最后的退路，所以只有英文：此时还没有任何画面可以显示 |

再试一次还是起不来，**就再点一次**：Android 没能启动时会把原因留在 Kindle 盘上，原厂这一侧下一次点击就读得到。如果是系统文件坏了，屏幕上会写"正在重装损坏的系统文件"，然后自己重装，不用接电脑。书和应用数据在另一个文件（`data.img`）里，不受影响。

（这一屏如果反复出现，那就不是这个文件的问题，而是 Kindle 的存储有问题——请备份你的书，并到项目主页报告。）

每次点"Readom"的过程都记录在 Kindle 盘的 `android/logs/<时间>/` 里，只留最近 5 次。报告问题时整个文件夹都可以附上：里面的内核日志按允许清单筛过，只留本项目用到的那些部分，序列号、MAC 地址、Wi‑Fi 名称这类东西不会写进去。

## 隐私

- 安装器只从本项目发行文件所在的那两个地址（GitHub Release 和 `readom.app`）下载，不上传任何数据。
- 屏幕波形、Wi‑Fi 校准这些每台机器独有的数据，每次启动时从你自己的 Kindle 上现场读取，不会离开这台设备。
