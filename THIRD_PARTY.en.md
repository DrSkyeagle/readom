## The GPL and LGPL components in the system image

Parsed out of the V40 system image's `/etc/NOTICE.html.gz` (2026-10-15, 121 licence blocks). A release has to accompany them with, or offer in writing, their complete corresponding source.

| File | Where it comes from (the AOSP project) | Licence | Needed on this machine? |
|---|---|---|---|
| `/kernel`, `/vendor/lib/modules/*.ko` | The Lab126 kernel plus `patches/android-core` | GPL-2.0-only | Needed |
| `iptables`, `ip6tables` | `external/iptables` | GPL-2.0 | Needed (netd) |
| `ip`, `ss`, `tc` and others | `external/iproute2` | GPL-2.0 | Needed |
| `e2fsck`, `mke2fs`, `blkid`, `e2fsdroid` and others | `external/e2fsprogs` | GPL-2.0 (the libraries LGPL/BSD) | Needed (ext4) |
| `libnl` | `external/libnl` | LGPL-2.1 | Needed |
| `libselinux` | `external/selinux` | The library itself is public domain; the project's NOTICE contains GPL text for other parts, so it is treated as GPL and its source accompanies the release | Needed |
| `libexif` | `external/libexif` | LGPL-2.1 | Needed (the gallery, image metadata) |
| `libcap` | `external/libcap` | BSD or GPL-2.0 | Needed |
| `core-oj.jar`, `libopenjdk.so`, `libopenjdkjvm*.so` | `libcore` (ojluni), `art/openjdkjvm*` | GPL-2.0 with the Classpath exception | Needed |
| `dnsmasq` | `external/dnsmasq` | GPL-2.0 | Unused: it is only for the hotspot and tethering, and the hotspot is off on this machine (`config_wifi_softap_supported=false`), so it never runs |
| `fsck.f2fs`, `make_f2fs` | `external/f2fs-tools` | GPL-2.0 | Unused: this machine uses only ext4, so they never run |
| `sgdisk` | `external/gptfdisk` | GPL-2.0 | Unused: it is only for partitioning external storage, and this machine has no card slot, so it never runs |
| `mmc_utils` | `external/mmc-utils` | GPL-2.0 | A debugging tool, tagged `debug`, so the `user` build a release is made from does not carry it |
| `gdbserver` | `prebuilts/misc` (the source being GDB) | GPL | A debugging tool, tagged `debug`, not in a `user` build (I8) |
| `libfec_rs.a` | `external/fec` | LGPL-2.1 | A static library, listed in the NOTICE |
| WebView, EinkBro, the pinyin dictionary | Above | LGPL-2.1, GPL-3.0-or-later, GPL-3.0-only | Needed |

**The three "unused" ones are kept** (assessed 2026-10-15):
- The gain is zero: the system image is a fixed-size file (512 MiB) read in full at boot, so removing these 400 KB or so does not shorten the read; they never run, so they occupy neither memory nor processor; compressed, they are about 0.2 MB of a roughly 196 MB package.
- The price: they come in through AOSP's general product definitions (`base.mk`, `core_minimal.mk`), and 8.1 has no way to remove a `PRODUCT_PACKAGES` entry from the device side, so it would mean patching `build/make` and carrying that patch through every sync afterwards.
- The source obligation does not grow because of them: the kernel, `iptables`, `iproute2`, `e2fsprogs` and the other necessary components already have to ship their source with the release, and the packaging script handles whatever the NOTICE lists together.
- The debugging tools (`gdbserver`, `mmc_utils`, and `su`, `strace` and `tcpdump`) are all tagged `debug` and stay out of the image automatically now that the build is `user`, with nothing else to change.

## Providing the source

- Every GitHub Release is accompanied by the source of every copyleft file in the image, generated by `tools/collect-copyleft-sources.py` tracing the image's NOTICE file by file, and checked to be the source the build used (`docs/design/release-build.en.md`, "the source that ships with a release"):
  - the AOSP projects' source archives;
  - Amazon's kernel source as it is;
  - EinkBro's and rime-ice's upstream source (`device/amazon/pw3/apps/sources.json`);
  - `SOURCES.md`: the source corresponding to each file.
- The contents of this repository at the release tag (the patches, the configuration, the build scripts, the handover module) are the rest of that source.
- Chromium's source archive is 6.7 GB, over GitHub's per-file limit, so it is offered in writing instead (valid for at least three years), stated in `SOURCES.md`.
- The build toolchain: AOSP `arm-linux-androideabi-4.9` (`0390252b`), musl 1.2.5, and an Ubuntu 22.04 build virtual machine.
